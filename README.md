# Home Brew Bench

Research-based buying guides for home coffee gear: grinders, drip and grind-and-brew coffee makers, espresso machines and grinders, kettles, scales, pour-over, French press, moka pots, cold brew, milk frothers, coffee canisters, travel brewers, gifts and stocking stuffers.

The site is served from this repository with GitHub Pages. Open `index.html` for the list of guides.

**How the guides are made:** we don't test products in person. Each guide compares specs, dated prices and published reviews from public sources, which are listed at the bottom of every page. The guides are researched and drafted with AI assistance.

**Links:** product links currently point to ordinary Amazon search results, and we earn nothing from them. If we join an affiliate program later, every page's disclosure will be updated first.
